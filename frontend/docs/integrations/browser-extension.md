# Browser Extension

Connect your second brain directly to your browser. The MemWyre browser extension allows you to capture content, save notes, and seamlessly inject memory into AI tools (like ChatGPT, Claude, and Gemini) without leaving your tab.

## Installation via Developer Mode

The MemWyre extension is currently distributed as a standalone ZIP file. You will need to install it manually using Chrome or Edge's built-in Developer Mode.

### Step 1: Download & Extract
1. Download the `extension.zip` file provided to you by MemWyre (usually available via your dashboard or direct link).
2. Extract/Unzip the contents of `extension.zip` into a folder on your computer. Keep this folder in a safe place, as moving or deleting it later will break the extension.

### Step 2: Load into Chrome/Edge
1. Open your browser and navigate to the Extensions page:
   - **Chrome**: Go to `chrome://extensions/`
   - **Edge**: Go to `edge://extensions/`
2. In the top right corner, toggle **Developer mode** to ON.
3. Click the **Load unpacked** button that appears.
4. Select the unzipped `extension` folder from Step 1.

The MemWyre extension should now appear in your browser's toolbar!

## Authentication & Setup

Before you can start saving memories, you must link the extension to your account:

1. Click the MemWyre icon in your browser toolbar to open the side panel.
2. Open the MemWyre Web App (`memwyre.tech`) in a new tab and go to **Settings**.
3. Click the **"Copy Extension Token"** button.
4. Paste this token into the extension popup when prompted.

## Features & Usage

Once installed and authenticated:
- **Seamless AI Integration**: The extension works out-of-the-box on sites like `chatgpt.com`, `claude.ai`, and `gemini.google.com`.
- **One-Click Capture**: Highlight any text, right-click, and select "Save to MemWyre" from the context menu.
- **Side Panel Search**: Quickly search your vault or review your inbox directly from the sidebar.
