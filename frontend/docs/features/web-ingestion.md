# Web Page Ingestion

MemWyre includes a powerful web scraping engine designed to extract clean, readable text from any URL you provide, turning articles and messy web pages into perfectly searchable memories.

## Overview

When you save a URL to MemWyre, our ingestion engine fetches the raw page, strips away the noise (like navigation bars, footers, advertisements, and scripts), and extracts only the core textual content. This ensures that your memory vault is populated with high-quality information, not clutter.

## How It Works

1. **Save a Link**: Paste a URL into the MemWyre Chat, add it via the Browser Extension, or save it as a new memory in your Inbox.
2. **Noise Reduction**: MemWyre instantly analyzes the page structure and removes non-essential HTML elements.
3. **Content Indexing**: The cleaned text is processed and embedded into your vector vault.

This makes it incredibly easy to build up a knowledge base of articles, research papers, and documentation simply by feeding MemWyre URLs. When you ask a question later, the AI will pull answers directly from the text of those saved web pages.
